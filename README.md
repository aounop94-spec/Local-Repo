Python Project Title

Purpose:
It converts temperature from Celsius to Fahrenheit.

How to Run the Program:
1. Ensure you have Python installed.
2. Run the main script via Command Prompt:
   ```cmd
   python main.py
   ```

Example Input / Output
Input:
Temperature (in Celsius): 100

Output:
Temperature (in Fahrenhiet): 212
